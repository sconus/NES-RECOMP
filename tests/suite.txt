# Test suite for `make test-ppu` (tests/run_tests.py).
#
#   kind  frames  rom  [input script]
#
# rom is relative to tests/roms/nes-test-roms, except paths starting with
# tests/ (ROMs made for this project). kind says how to judge it:
#   result  blargg $6000 protocol; passes when the status byte is $00.
#           The run stops early once the ROM reports.
#   text    result shown on screen only; passes when a line reads
#           "Passed" (any case) or "$01".
#   frame   homebrew; the final frame must match the saved picture
#           (a regression check, not a correctness check).
#   audio   the sound (--wav) must match the saved recording (regression).
#   silence apu_mixer: between its two beeps the sound must be near silent
#           (see SILENCE_LIMIT in run_tests.py).
# frames is the most frames to run.
